## 🖥️ Interactive Command Center Web Application

The repository includes a modern, high-aesthetic dark glassmorphic web application (`index.html`, `styles.css`, `data.js`, `app.js`):

1. **Team Command & Flywheel Dashboard:** Live multi-agent synchronization monitor.
2. **Product Intelligence Simulator:** Interactive 100-Point Scorecard calculator with real-time tier grading.
3. **Brand & Content Strategy Suite:** Follower Magnet litmus tester, 70/20/10 visualizer, and 5-part script generator.
4. **Creative Production Engine:** Anti-Generic Hook guardrails, 10 Curiosity Archetypes drawer, 30-Day Pipeline explorer, and Hook A/B/C variant switcher with 1-click script copier.
5. **TikTok Shop Growth & Funnel Optimizer:** 7-Stage Funnel Visualizer, 5 Failure Triage Simulator, and Affiliate & Creator CRM with personalized pitch generator.
6. **Performance & QA Compliance Scanner:** Pre-Flight 9-point checklist, Live Policy Claim Scanner with instant compliant rewrites, Weekly WIN/LEARN/KILL matrix with 5-factor root cause analyzer, and Voice-of-Customer to Video brief transformer.
7. **Shop Economics & Margins:** Landed cost and contribution margin waterfall calculator.
8. **Playbooks & SOP Vault:** Built-in modal reader for all agent markdown specifications.
